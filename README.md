# GameCaptioner

GameCaptioner is a gaming-focused content generation prototype built for creators who want faster multi-platform content workflows.

##Live Demo: 
https://your-vercel-link

## What it does

- Generates gaming captions by platform
- Generates voiceovers
- Generates CTAs
- Generates carousel slide text
- Supports single-platform generation
- Supports all-platform generation
- Exports output for Sheets workflows
- Includes basic typo cleanup

## Platforms supported

- YouTube
- Instagram
- Facebook
- Twitter/X
- LinkedIn

## Built with

- Next.js
- React
- TypeScript
- Tailwind CSS

## Current status

This is an MVP prototype focused on gaming content creation workflows.

## Future plans
